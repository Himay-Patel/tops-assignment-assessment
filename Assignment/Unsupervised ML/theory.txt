MACHINE LEARNING: CLUSTERING ALGORITHMS & UNSUPERVISED LEARNING EVALUATION
=======================================================================

1. CLUSTERING ALGORITHMS AND THEIR USE CASES
===========================================

1.1 WHAT IS CLUSTERING?
-----------------------
Clustering is an unsupervised machine learning technique that groups similar data points together based on their characteristics. Unlike supervised learning, clustering doesn't use labeled data - it discovers natural patterns and groupings within the data.

Key Characteristics:
- Unsupervised learning (no labels)
- Discovers hidden patterns
- Groups similar data points
- Identifies data structure

1.2 TYPES OF CLUSTERING ALGORITHMS
----------------------------------

A. PARTITION-BASED CLUSTERING
   --------------------------
   These algorithms partition data into k clusters where each data point belongs to exactly one cluster.

   1. K-MEANS CLUSTERING
      - How it works:
        * Randomly initialize k centroids
        * Assign each point to nearest centroid
        * Recalculate centroids as mean of assigned points
        * Repeat until convergence

      - Use Cases:
        * Customer segmentation
        * Document classification
        * Image compression
        * Market basket analysis

      - Advantages:
        * Simple and fast
        * Scalable to large datasets
        * Easy to interpret

      - Limitations:
        * Requires specifying k
        * Sensitive to initial centroids
        * Assumes spherical clusters
        * Sensitive to outliers

   2. K-MEDOIDS
      - Similar to K-means but uses actual data points as centers
      - More robust to outliers
      - Use cases: Retail location planning, facility location

B. HIERARCHICAL CLUSTERING
   ----------------------
   Builds a tree of clusters (dendrogram) showing data relationships at different scales.

   1. AGGLOMERATIVE CLUSTERING (Bottom-up)
      - Starts with each point as individual cluster
      - Merges closest clusters iteratively
      - Use Cases:
        * Biological taxonomy
        * Social network analysis
        * Document hierarchy
        * Gene expression analysis

   2. DIVISIVE CLUSTERING (Top-down)
      - Starts with one cluster containing all points
      - Splits clusters recursively
      - Use Cases:
        * Market segmentation
        * Organizational structure

   Advantages:
   - No need to specify number of clusters
   - Provides hierarchical relationship
   - Visual representation (dendrogram)

   Limitations:
   - Computationally expensive O(n³)
   - Sensitive to noise and outliers

C. DENSITY-BASED CLUSTERING
   ------------------------
   Finds clusters based on dense regions of data points.

   1. DBSCAN (Density-Based Spatial Clustering)
      - How it works:
        * Identifies core points, border points, and noise
        * Expands clusters from core points
        * Parameters: eps (neighborhood radius), min_samples

      - Use Cases:
        * Anomaly detection
        * Geographic data analysis
        * Astronomy data
        * Network intrusion detection

      - Advantages:
        * Doesn't require specifying k
        * Handles arbitrary cluster shapes
        * Robust to outliers

      - Limitations:
        * Struggles with varying densities
        * Sensitive to parameters

   2. OPTICS
      - Extension of DBSCAN
      - Handles varying densities better
      - Creates reachability plot

D. DISTRIBUTION-BASED CLUSTERING
   -----------------------------
   Assumes data comes from mixture of probability distributions.

   1. GAUSSIAN MIXTURE MODELS (GMM)
      - Assumes clusters follow Gaussian distributions
      - Uses Expectation-Maximization algorithm
      - Use Cases:
        * Image segmentation
        * Speech recognition
        * Anomaly detection
        * Financial modeling

      - Advantages:
        * Soft clustering (probabilistic assignments)
        * Flexible cluster shapes

      - Limitations:
        * Assumes Gaussian distribution
        * Can converge to local optima

E. GRID-BASED CLUSTERING
   ---------------------
   Divides data space into grid cells.

   1. STING (Statistical Information Grid)
   2. CLIQUE

   Use Cases:
   - Spatial data mining
   - Large dataset processing

2. MODEL EVALUATION TECHNIQUES IN UNSUPERVISED LEARNING
======================================================

2.1 CHALLENGES IN UNSUPERVISED LEARNING EVALUATION
--------------------------------------------------
- No ground truth labels
- Subjectivity in cluster interpretation
- Multiple valid clustering solutions
- Domain knowledge dependency

2.2 INTERNAL VALIDATION METRICS
-------------------------------
These metrics evaluate clustering quality using only the data itself, without external labels.

A. SILHOUETTE SCORE
   - Measures how similar a point is to its own cluster vs other clusters
   - Range: -1 to 1 (higher is better)
   - Formula: s(i) = (b(i) - a(i)) / max(a(i), b(i))
     where a(i) = average distance to points in same cluster
           b(i) = average distance to points in nearest other cluster

   Interpretation:
   * 1: Perfect clustering
   * 0: Overlapping clusters
   * -1: Completely wrong clustering

B. CALINSKI-HARABASZ INDEX
   - Ratio of between-cluster dispersion to within-cluster dispersion
   - Higher values indicate better clustering
   - Formula: CH = [BSS/(k-1)] / [WSS/(n-k)]
     where BSS = between-cluster sum of squares
           WSS = within-cluster sum of squares

C. DAVIES-BOULDIN INDEX
   - Average similarity between each cluster and its most similar one
   - Lower values indicate better clustering
   - Measures cluster separation and compactness

D. DUNN INDEX
   - Ratio of smallest between-cluster distance to largest within-cluster distance
   - Higher values indicate better clustering
   - Sensitive to noise

2.3 EXTERNAL VALIDATION METRICS
-------------------------------
Used when true labels are available (for validation purposes).

A. ADJUSTED RAND INDEX (ARI)
   - Measures similarity between two clusterings
   - Adjusts for chance agreement
   - Range: -1 to 1 (1 = perfect agreement)

B. NORMALIZED MUTUAL INFORMATION (NMI)
   - Measures mutual information between clusterings
   - Normalized to account for different numbers of clusters
   - Range: 0 to 1 (1 = perfect agreement)

C. HOMOGENEITY, COMPLETENESS, V-MEASURE
   - Homogeneity: Each cluster contains only members of single class
   - Completeness: All members of given class assigned to same cluster
   - V-measure: Harmonic mean of homogeneity and completeness

2.4 VISUALIZATION TECHNIQUES
----------------------------

A. DENDROGRAM
   - Shows hierarchical relationship between clusters
   - Helps determine optimal number of clusters
   - Useful for agglomerative clustering

B. PCA PLOTS
   - Projects high-dimensional data to 2D/3D
   - Colors points by cluster assignment
   - Shows cluster separation

C. t-SNE PLOTS
   - Non-linear dimensionality reduction
   - Preserves local structure better than PCA
   - Good for visualizing high-dimensional clusters

D. SILHOUETTE PLOTS
   - Visualizes silhouette scores for each cluster
   - Shows cluster quality and size

2.5 STABILITY-BASED EVALUATION
------------------------------

A. BOOTSTRAPPING
   - Resample data multiple times
   - Check consistency of clustering results
   - Measures algorithm stability

B. JACCARD SIMILARITY
   - Compares cluster assignments across different runs
   - Measures algorithm robustness

2.6 DOMAIN-SPECIFIC EVALUATION

A. BUSINESS METRICS

B. INTERPRETABILITY

Step 1: Data Preparation
